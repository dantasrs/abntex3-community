# ABNT NBR 14724:2024 — matriz de requisitos

Esta matriz registra interpretações próprias para implementação. Ela não
reproduz a norma, não a substitui e não representa declaração de
conformidade.

## Escopo implementado

Os Marcos 4 a 7 cobrem as regras gerais mensuráveis de formato, margens,
espaçamento, paginação, elementos pré e pós-textuais e o fluxo completo do
perfil acadêmico.

## Evidências e revisão

Os testes comparam dimensões, modos de impressão, visibilidade dos números,
continuidade, páginas em branco, paridade e espaçamentos nos três motores
declarados. Os exemplos `examples/layout-paginacao.tex`,
`examples/elementos-pretextuais.tex` e `examples/trabalho-academico.tex`
demonstram a API pública.

Antes de qualquer alegação de conformidade ainda é necessária revisão
normativa independente.
