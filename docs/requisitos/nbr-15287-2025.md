# ABNT NBR 15287:2025 — matriz de requisitos

Esta matriz registra interpretações próprias para implementação. Ela não
reproduz a norma, não a substitui e não representa declaração de
conformidade.

## Escopo implementado

O Marco 8 cobre a estrutura e as regras gerais observáveis do perfil de
projeto de pesquisa, reutilizando os módulos comuns do pacote.

## Evidências e revisão

Os testes verificam o fluxo, a opcionalidade da capa, os elementos
obrigatórios e o registro das cinco divisões textuais. O exemplo
`examples/projeto-pesquisa.tex` demonstra o perfil completo.

Antes de qualquer alegação de conformidade ainda é necessária revisão
normativa independente.
