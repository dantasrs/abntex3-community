# abnTeX3 Community 0.1.0-alpha.1

Esta é a primeira pré-release pública do projeto. Ela existe para permitir
ensaios, migrações e revisão por pessoas usuárias de LaTeX; não é recomendada
para produção e não representa alegação de conformidade com normas da ABNT.

## Escopo desta alfa

- pacote modular carregável sobre `article`, `report` e `book`;
- perfis experimentais acadêmico, projeto de pesquisa, artigo, relatório e
  livro ou folheto;
- integração com `biblatex-abnt` e `biber`;
- modelos canônicos, testes de regressão e matriz Linux, Windows e macOS;
- metadados PDF e auditoria inicial de qualidade e portabilidade.

## Artefatos

- `abntex3-ctan.zip`: árvore de fontes, documentação e exemplos;
- `abntex3.tds.zip`: instalação pronta para uma árvore TDS;
- `SHA256SUMS`: resumos SHA-256 dos dois arquivos.

As instruções de instalação, verificação e envio de relatos estão no
[guia do teste alfa](https://github.com/dantasrs/abntex3-community/blob/v0.1.0-alpha.1/docs/teste-alfa.md).

## Limitações

- a API `0.x` pode mudar entre pré-releases;
- as matrizes normativas ainda aguardam revisão independente;
- o projeto não produz nem anuncia PDF/UA;
- os artefatos não são enviados ao CTAN nesta fase.
